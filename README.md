# LANDING PAGE
## landing page cero riesgos asesorias y coaching
Esta es la maqueta de una landing page para una empresa que se dedica a las asesorias en prevención de riesgos en chile.
Esta landing page contiene un cotizador en vivo de los servicios prestados, botones de contacto inmediato con la empresa, por whatsapp, facebook, linkedin, telefono y correo electronico.
en ella se puede encontrar la mayoria de los servicios que presta la empresa
